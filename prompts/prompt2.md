# PROMPT 2 — DM EMPRESARIAL

## DESIGN SYSTEM + DIREÇÃO VISUAL

### Identidade Digital, Interface, Tipografia, Composição e Motion

---

# 0. PAPEL

Você é um **Creative Director, Brand Designer, Senior Product Designer, Art Director e UX/UI Designer** especializado em marcas empresariais, consultorias, instituições e experiências digitais premium.

Sua missão é transformar o **Product + UX Blueprint da DM Empresarial** em uma **direção visual completa, coerente e implementável**.

O resultado desta etapa será a especificação visual que posteriormente será utilizada pela equipe/agente de desenvolvimento.

---

# 1. CONTEXTO

A DM Empresarial está construindo uma nova plataforma digital composta por:

- institucional;
- soluções;
- serviços;
- especialistas;
- blog;
- conteúdo editorial;
- geração de leads;
- autoridade empresarial.

A referência estratégica utilizada durante o planejamento foi a Sequoia Estratégia e Marketing.

A referência NÃO deve ser utilizada para copiar:

- identidade visual;
- cores;
- tipografia;
- layout;
- composição;
- imagens;
- animações;
- componentes;
- textos;
- código.

A referência serve apenas para estudar:

- percepção de autoridade;
- organização editorial;
- hierarquia;
- apresentação de consultoria;
- relação entre conteúdo e negócio;
- experiência institucional.

A identidade final deve ser **inequivocamente DM Empresarial**.

---

# 2. OBJETIVO VISUAL

A plataforma deve transmitir simultaneamente:

- autoridade;
- inteligência;
- experiência;
- confiança;
- proximidade;
- sofisticação;
- clareza;
- maturidade empresarial.

A percepção desejada é:

> "Essa empresa entende negócios e sabe o que está fazendo."

Não queremos:

> "Essa é uma startup de tecnologia."

Nem:

> "Esse é um template corporativo."

Nem:

> "Isso parece um site gerado automaticamente."

---

# 3. PERSONALIDADE VISUAL

Defina a personalidade visual da DM através destes eixos:

```text
SOFISTICADA
sem ser elitista

EMPRESARIAL
sem ser burocrática

MODERNA
sem seguir tendências passageiras

HUMANA
sem parecer informal demais

EDITORIAL
sem parecer revista

SÓBRIA
sem parecer fria

PREMIUM
sem parecer luxuosa artificialmente
```

A interface deve possuir personalidade.

---

# 4. PRINCÍPIO FUNDAMENTAL

Não criar uma estética baseada em efeitos.

Criar uma estética baseada em:

```text
TIPOGRAFIA
+
ESPAÇO
+
COMPOSIÇÃO
+
IMAGEM
+
HIERARQUIA
+
CONTRASTE
+
MOVIMENTO
```

Se a interface precisar de dezenas de efeitos para parecer sofisticada, a direção visual está errada.

---

# 5. REFERÊNCIA ESTÉTICA

A direção deve combinar:

### CONSULTORIA EMPRESARIAL

com

### PUBLICAÇÃO EDITORIAL

com

### BRANDING CONTEMPORÂNEO

com

### EXPERIÊNCIA DIGITAL PREMIUM

O resultado deve parecer desenvolvido por um estúdio especializado em posicionamento empresarial.

---

# 6. O QUE EVITAR

Não utilizar como linguagem visual principal:

- neon;
- cyberpunk;
- estética hacker;
- glassmorphism excessivo;
- gradientes genéricos;
- blobs;
- 3D gratuito;
- excesso de sombras;
- excesso de border-radius;
- cards iguais repetidos;
- ícones gigantes;
- dashboards;
- estética SaaS;
- estética startup;
- estética "AI generated";
- excesso de animações;
- efeitos de partículas;
- parallax exagerado;
- títulos em caixa alta em absolutamente tudo;
- microtexto decorativo sem função.

---

# 7. DIREÇÃO DE ARTE

Defina uma direção de arte baseada em:

## ESPAÇO

Utilizar espaço negativo de forma deliberada.

Não preencher todos os espaços vazios.

## ESCALA

Criar contraste entre:

- elementos gigantes;
- elementos pequenos;
- texto editorial;
- microinformações.

## ASSIMETRIA

Utilizar composição assimétrica quando melhorar a experiência.

Não criar simetria apenas por segurança.

## RITMO

A página deve alternar entre:

```text
IMPACTO
↓
RESPIRAÇÃO
↓
INFORMAÇÃO
↓
IMPACTO
↓
PROFUNDIDADE
```

---

# 8. GRID

Defina um sistema de grid profissional.

Especificar:

- largura máxima do conteúdo;
- número de colunas;
- gutters;
- margens;
- breakpoints;
- comportamento mobile;
- comportamento tablet;
- comportamento desktop;
- comportamento widescreen.

Criar uma lógica consistente.

Evitar que cada seção invente seu próprio grid.

---

# 9. CONTAINER

Definir:

- largura máxima;
- padding horizontal;
- comportamento por breakpoint;
- alinhamento;
- relação com viewport.

A largura deve favorecer leitura editorial.

Não criar conteúdo excessivamente largo.

---

# 10. SPACING SYSTEM

Criar uma escala de espaçamento consistente.

Definir tokens para:

```text

xs
sm
md
lg
xl
2xl
3xl

5xl
```

Usar o sistema em:

- seções;
- títulos;
- parágrafos;
- cards;
- navegação;
- formulários;
- artigos;
- rodapé.

Não utilizar espaçamentos aleatórios.

---

# 11. TIPOGRAFIA

A tipografia será uma das principais ferramentas de identidade.

Não escolher fonte apenas porque está na moda.

Avaliar:

- personalidade;
- legibilidade;
- presença editorial;
- números;
- acentos do português;
- pesos;
- largura;
- leitura longa;
- títulos grandes;
- mobile;
- performance.

Definir:

```text
DISPLAY
HEADLINE
BODY
UI
CAPTION
```

Pode utilizar uma família única ou combinação de famílias.

Se utilizar combinação:

definir claramente o papel de cada uma.

---

# 12. HIERARQUIA TIPOGRÁFICA

Criar escala completa:

```text
Display XL
Display L
Display M

H1
H2
H3
H4

Body Large
Body
Body Small

Label
Caption
Metadata
```

Para cada nível definir:

- font-size;
- line-height;
- weight;
- letter-spacing;
- uso recomendado;
- comportamento mobile.

---

# 13. TÍTULOS

Os títulos devem possuir presença.

Evitar:

```text
"Conheça nossas soluções"
```

em 48 variações visualmente idênticas.

Criar diferentes tratamentos:

- headline editorial;
- headline institucional;
- headline comercial;
- headline de artigo;
- headline de seção.

A tipografia deve ajudar a construir narrativa.

---

# 14. CORES

Criar uma paleta própria para a DM.

Não copiar cores da referência.

Definir:

```text
Primary
Secondary
Accent
Background
Surface
Surface Muted
Text Primary
Text Secondary
Text Muted
Border
Success
Warning
Error
```

Criar versões para:

- fundo claro;
- fundo escuro, caso exista;
- estados interativos.

---

# 15. REGRAS DE COR

A paleta deve ser contida.

Não transformar o site em uma explosão cromática.

Definir:

- cor dominante;
- cor de apoio;
- cor de destaque;
- neutros;
- proporção aproximada de utilização.

A cor de destaque deve possuir função.

Não utilizar cor apenas para decorar.

---

# 16. CONTRASTE

Garantir contraste suficiente para:

- textos;
- botões;
- links;
- labels;
- inputs;
- estados;
- navegação.

A estética nunca deve comprometer acessibilidade.

---

# 17. IMAGENS

A fotografia deve funcionar como elemento de marca.

Definir direção fotográfica.

A imagem deve parecer:

- real;
- empresarial;
- humana;
- sofisticada;
- documental;
- contextual.

Evitar:

- banco de imagens corporativas óbvias;
- pessoas sorrindo artificialmente para a câmera;
- apertos de mão;
- executivos olhando para gráficos genéricos;
- escritórios falsamente luxuosos;
- imagens clichês de negócios.

Priorizar imagens que transmitam:

- pessoas;
- decisões;
- trabalho;
- empresas;
- cidade;
- contexto regional;
- interação;
- experiência.

---

# 18. IMAGENS DA EQUIPE

Especialistas devem parecer pessoas reais.

Definir:

- proporção;
- enquadramento;
- tratamento;
- fundo;
- iluminação;
- consistência entre retratos.

Evitar transformar especialistas em:

```text
"headshots corporativos genéricos"
```

A fotografia deve transmitir competência sem artificialidade.

---

# 19. FOTOGRAFIA REGIONAL

Como a DM possui atuação em Frutal/MG e região, considerar a possibilidade de utilizar elementos visuais regionais.

IMPORTANTE:

Não transformar isso em turismo ou propaganda da cidade.

A regionalidade deve funcionar como:

```text
CONTEXTO
+
IDENTIDADE
+
PROXIMIDADE
```

e não como decoração.

---

# 20. ICONOGRAFIA

Criar uma linguagem de ícones consistente.

Definir:

- estilo;
- espessura;
- tamanho;
- preenchimento;
- raio;
- utilização.

Não misturar vários estilos de ícones.

Ícones devem complementar a informação.

---

# 21. BOTÕES

Criar sistema de botões:

```text
Primary
Secondary
Tertiary
Text
Icon
```

Definir:

- altura;
- padding;
- tipografia;
- radius;
- borda;
- estados;
- hover;
- focus;
- active;
- disabled.

O CTA principal da marca deverá ser reconhecível.

---

# 22. CARDS

Não criar um único componente "Card" e utilizar em tudo.

Definir diferentes padrões:

```text
Article Card
Solution Card
Expert Card
Case Card
Content Card
```

Cada um deverá existir porque possui uma necessidade diferente.

Evitar:

```text

```

# 23. ARTIGOS

O design editorial deve priorizar leitura.

Definir:

- largura ideal da coluna;
- largura máxima;
- tamanho da fonte;
- line-height;
- hierarquia H1-H4;
- citações;
- listas;
- imagens;
- legendas;
- links;
- tabelas;
- blocos destacados;
- autor;
- metadata.

O artigo deve parecer uma publicação profissional.

---

# 24. HOME — DIREÇÃO VISUAL

Criar uma direção visual específica para cada bloco.

## HERO

Deve possuir forte impacto.

Não precisa necessariamente ocupar 100vh.

Deve existir:

- headline;
- contexto;
- CTA;
- elemento visual.

---

## SOLUÇÕES

Evitar quatro cards idênticos.

Criar hierarquia.

Pode utilizar:

- composição assimétrica;
- blocos de tamanhos diferentes;
- tipografia;
- números;
- imagens;
- interação.

---

## SOBRE

Deve possuir sensação institucional.

Utilizar:

- narrativa;
- imagem;
- indicadores;
- espaço negativo.

---

## ESPECIALISTAS

Não tratar como uma simples grade de funcionários.

A seção deve transmitir:

```text
PESSOAS
+
EXPERIÊNCIA
+
AUTORIDADE
```

---

## CONTEÚDO

A seção editorial deve parecer parte de uma publicação.

Criar hierarquia entre:

- artigo principal;
- artigos secundários;
- categorias.

Não fazer uma grade uniforme.

---

## PROVA

Quando houver dados reais:

utilizar design editorial para apresentá-los.

Nunca criar números apenas para preencher espaço.

---

# 25. PÁGINA DE SOLUÇÃO

Criar uma identidade visual própria para páginas profundas.

A página deve possuir sensação de:

↓

↓
SOLUÇÃO

Não parecer landing page de anúncio.

---

# 26. PÁGINA DE ESPECIALISTA

Criar:

- grande retrato;
- nome;
- especialidade;
- biografia;
- experiência;
- conteúdos;
- soluções relacionadas.

A pessoa deve parecer uma autoridade, não apenas um funcionário.

---

# 27. BLOG

Definir:

- hero;
- destaque;
- categorias;
- busca;
- artigos;
- filtros;
- paginação;
- estados vazios.

O blog não deve parecer um CMS.

Deve parecer uma publicação.

---

# 28. CONTATO

```text
PROXIMIDADE
+
CONFIANÇA
+
AÇÃO
```

O formulário deve ser visualmente simples.

# 29. FORMULÁRIOS

- input;

# 30. NAVEGAÇÃO

## MOBILE

- menu;

# 31. HEADER

Header no topo.

### Estado scroll

Header após rolagem.

### Estado mobile

Menu mobile.

### Estado página interna

Comportamento consistente.

Não criar header diferente em cada página sem motivo.

---

# 32. FOOTER

O footer deve ser visualmente forte, mas não exagerado.

Deve funcionar como:

```text
NAVEGAÇÃO
+
IDENTIDADE
+
CONTATO
+
CONFIANÇA
```

---

# 33. BORDER RADIUS

Não utilizar radius automaticamente em tudo.

Definir uma filosofia.

Exemplo:

```text
Inputs
Buttons
Cards
Images
Containers
```

Cada categoria pode possuir comportamento diferente.

O objetivo é criar uma linguagem sofisticada e coerente.

---

# 34. BORDAS E DIVISORES

Utilizar linhas e divisores quando ajudarem:

- estrutura;
- ritmo;
- hierarquia;
- leitura editorial.

Evitar transformar toda seção em uma caixa.

---

# 35. SOMBRAS

Sombras devem ser discretas.

Não utilizar sombras pesadas em todos os componentes.

A profundidade deve vir principalmente de:

- espaço;
- contraste;
- escala;
- cor;
- imagem.

---

# 36. MOTION DESIGN

A animação deve comunicar qualidade.

Não deve chamar atenção para si mesma.

Princípios:

```text
INTENCIONAL
DISCRETA
RÁPIDA
NATURAL
CONSISTENTE
```

---

# 37. ANIMAÇÕES PRIORITÁRIAS

Considerar:

### Reveal tipográfico

Títulos aparecendo de forma elegante.

### Image reveal

Imagens entrando de maneira natural.

### Hover

Microinterações discretas.

### Navigation

Transições suaves.

### Page transition

Somente se melhorar a percepção de continuidade.

### Scroll interaction

Somente quando contribuir para narrativa.

---

# 38. ANIMAÇÕES PROIBIDAS COMO PADRÃO

Não aplicar automaticamente:

- fade-in em tudo;
- slide-up em todos os cards;
- parallax em todas as imagens;
- texto voando;
- zoom constante;
- cursor customizado exagerado;
- partículas;
- efeitos de glitch;
- animações infinitas.

---

# 39. REDUCED MOTION

Toda animação deve respeitar:

```text
prefers-reduced-motion
```

Usuários que solicitarem redução de movimento devem receber uma experiência totalmente funcional.

---

# 40. RESPONSIVIDADE

```text

375px
390px
414px

768px

1024px
1280px
1440px
1920px
```

Não tratar mobile como desktop reduzido.

Definir mudanças reais de composição.

---

# 41. MOBILE

No mobile:

- preservar hierarquia;
- reduzir complexidade;
- reorganizar composição;
- preservar impacto;
- reduzir animações quando necessário;
- manter CTAs acessíveis;
- preservar leitura editorial.

Não simplesmente empilhar tudo.

---

# 42. ACESSIBILIDADE VISUAL

Considerar:

- contraste;
- tamanho mínimo de texto;
- focus states;
- navegação por teclado;
- labels;
- hierarquia semântica;
- reduced motion;
- alt text;
- legibilidade.

Acessibilidade não deve parecer uma camada adicionada depois.

---

# 51. PERFORMANCE VISUAL

A direção visual deve considerar performance desde o início.

Priorizar:

- imagens otimizadas;
- formatos modernos;
- lazy loading;
- fontes cuidadosamente escolhidas;
- animações leves;
- poucos assets pesados.

Não criar uma experiência visual impossível de carregar.

---

# 52. DESIGN ≠ DECORAÇÃO

Cada decisão visual precisa responder:

```text
Por que isso existe?
```

Se o elemento não:

- comunica;
- orienta;
- hierarquiza;
- melhora compreensão;
- melhora interação;
- fortalece a marca;

questionar sua necessidade.

---

# 53. CRITÉRIO DE QUALIDADE

Avaliar o design em cinco dimensões:

### 1. MARCA

Parece DM?

### 2. USABILIDADE

É fácil utilizar?

### 3. AUTORIDADE

Transmite conhecimento e experiência?

### 4. EDITORIAL

O conteúdo possui valor visual?

### 5. CONVERSÃO

O usuário sabe qual próximo passo pode tomar?

---

# 54. TESTE DE "SITE DE IA"

Antes de aprovar a direção, fazer o seguinte teste:

Pergunte:

> "Se eu remover o logotipo da DM, esse site poderia pertencer a qualquer consultoria?"

Se a resposta for sim:

A identidade está genérica demais.

Refinar.

---

# 55. TESTE DE TEMPLATE

Pergunte:

> "Se eu trocar o texto e as imagens, a interface continua parecendo exatamente igual a centenas de templates?"

Se sim:

Refinar a direção.

A composição deve possuir personalidade.

---

# 56. TESTE DE SOBRIEDADE

Pergunte:

> "O design está tentando provar que é premium?"

Se sim:

reduzir efeitos.

Premium deve ser percebido pela qualidade, não anunciado pela interface.

# 61. PRINCÍPIO FINAL

A DM Empresarial não precisa parecer uma empresa de tecnologia.

Ela precisa parecer uma empresa que:

**entende empresas.**

O design deve transmitir:

> experiência sem arrogância;

> sofisticação sem ostentação;

> inteligência sem complexidade;

> proximidade sem amadorismo;
